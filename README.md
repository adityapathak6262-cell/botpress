# Echo Cave Mystery Bot 🦇

## About
This is an interactive riddle-based chatbot built using **Botpress**. It challenges users with a mystery riddle ("Echo Cave Mystery") and evaluates their guesses using custom flow logic. 

## Features
- 🧩 **Interactive Riddle Flow:** Guides the user through a mysterious cave puzzle.
- 🔁 **Retry Logic:** Custom flow that loops incorrect answers back to the question smoothly.
- 🚀 **Built with Botpress Studio:** Node-based conversation architecture.

## How to Run / Test
1. Download the exported Botpress file from this repository.
2. Go to your [Botpress Cloud](https://app.botpress.cloud/) workspace.
3. Create a new bot and select "Import".
4. Upload the downloaded file and click "Train" to test it in the emulator!
